CaseCraft is a simple static frontend web application built as a learning project.
It showcases a modern e-commerce storefront for engineered shockproof phone cases.
The project is designed with a clean, minimalist layout and features a single-page view-switching navigation system.

TECHNOLOGIES USED

HTML5 (Semantic structure)

CSS3 (Styling and layout)

Vanilla JavaScript (DOM manipulation and page navigation)

Font Awesome (Icons)
FEATURES

Home Page with a welcome hero section and a "Shop Now" navigation button.

Product Catalog displaying various phone cases with images, titles, and prices.

Shopping Cart and Checkout views.

Responsive design for different screen sizes.

HOW TO RUN THE PROJECT

Clone or download this repository to your local computer.

Open the project folder.

Double-click on the "index.html" file or open it using any modern web browser (Chrome, Firefox, Edge, Safari).

PROJECT STRUCTURE

index.html: Contains the main structure and view sections of the website.

style.css: Contains all the styling, layout, and responsiveness rules.

script.js: Manages dynamic product loading, navigation, and page interactions.
